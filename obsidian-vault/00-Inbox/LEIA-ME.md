# Inbox

Tudo entra aqui. Não pense, só escreva.

Uma vez por semana (sugestão: sexta 17h) você abre esta pasta e decide para cada nota:
- vira **operação / cliente / motorista** → `02-Videl`
- vira **projeto** (tem entregável e prazo) → `04-Projetos`
- vira **referência** (consulta futura) → `05-Referencias`
- é **pessoal** → `03-Pessoal`
- não serve → apaga sem dó
