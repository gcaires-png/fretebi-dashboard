# Projetos

Um projeto tem: **entregável claro** + **data de fim**.
Se não tem as duas coisas, não é projeto — é área (vai para `02-Videl` ou `03-Pessoal`).

Exemplos válidos: "Integrar API Bsoft", "Migrar time para o novo painel", "Trocar de carro".

Ao terminar, mova para `05-Referencias` ou apague.
